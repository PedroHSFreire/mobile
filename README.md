# Semente Verde

Aplicativo Flutter de hábitos sustentáveis, desenvolvido para a OAT Unidade 2.

## O que o app faz

- Adiciona, conclui e remove hábitos sustentáveis.
- Salva a lista no aparelho e recupera os dados quando o app abre.
- Mostra uma segunda tela com progresso e dica sustentável do dia.

## Executar e gerar o APK

Com Flutter e Android SDK configurados:

```bash
flutter pub get
flutter run
flutter build apk --release
```

O APK fica em `build/app/outputs/flutter-apk/app-release.apk`. Uma execução do workflow do GitHub Actions também gera esse APK como artefato para baixar.
